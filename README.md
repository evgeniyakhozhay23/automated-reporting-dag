# Автоматизация отчетности и отправление в мессенджер
- Отчет о ленте новостей
- Полный отчет по приложению 
### Источник
Karpov Courses, курс "Симулятор Аналитика", https://karpov.courses/simulator

Данные с 02.05.2026 до текущего дня (обновляются в режиме реального времени). Данные предоставлены в рамках курса, хранятся в Clickhouse.

### Структура данных
Провожу работу с данными стартапа приложения с лентой новостей (feed_actions) и мессенджером (message_actions). 

Таблица feed_actions - информация о действиях пользователей в приложении ленты новостей:
- user_id - идентификационный номер пользователя
- post_id - номер поста
- action - вид действия пользователя в ленте (категориальная переменная). Значения - like и view.
- time - дата и время действия пользователя в ленте новостей
- gender - пол пользователя
- age - возраст пользователя
- country - страна проживания пользователя
- city - город проживания пользователя
- os - операционная система устройства, с которого заходят в приложение. Значения: iOS, Android
- source - канал привлечение клиентов: ads (через рекламу), organic (самостоятельно)
- exp_group - группа пользователя для проведения эксперимента

Таблица message_actions - информация о пользователях мессенджера
- user_id - идентификационный номер пользователя
- receiver_id - идентификационный номер получателя
- time - дата и время отправки сообщения
- source - канал привлечение клиентов: ads (через рекламу), organic (самостоятельно)
- exp_group - группа пользователя для проведения эксперимента
- gender - пол пользователя
- age - возраст пользователя
- country - страна проживания пользователя
- city - город проживания пользователя
- os - операционная система устройства, с которого заходят в приложение
  
### Инструменты для работы
Python, выгрузка данных из Clickhouse, Aiflow, Github, создание Телеграм бота



## 1. Отчет по ленте новостей
### Задание
Напишите скрипт для сборки отчета по ленте новостей. Отчет должен состоять из двух частей:
- текст с информацией о значениях ключевых метрик за предыдущий день
- график с значениями метрик за предыдущие 7 дней
Отобразите в отчете следующие ключевые метрики: DAU, просмотры, лайки, CTR

### Содержание DAG
Предварительно я создала свой бот в Телеграмм. Этот бот должен отсылать отчеты в общий чат (создан организаторами в рамках курса).
- Таск 1: Выгрузка данных из таблицы feed_actions в Clickhouse
- Таск 2: Преобразование данных (группировка по дате), чтобы дата воспринималась как отдельный столбец (особенности Airflow)
- Таск 3: Текст отчета о значениях ключевых метрик за предыдущий день. Создание текстового сообщения для отправки в Телеграмм
- Таск 4: График с значениями метрик за предыдущие 7 дней. Создание plot object для отправки в Телеграмм.

(По причине блокировки Телеграмм автоматическое отправление в мессенджер через DAG ограничено. Строка кода для отправки указана через "#", как комментарий)

## 2. Полный отчет по приложению 
### Задание
Подготовить отчет по всему приложению (включая мессенджер). Продумать, какие метрики включить. В отчете обязательно должны присутствовать метрики приложения как единого целого, или можно отобразить метрики по каждой из частей приложения — по ленте новостей и по мессенджеру.  Показать динамику метрик. Автоматизировать отправку отчета с помощью Airflow. 

### Содержание DAG
- Таски 1 и 2: Выгрузка данных из таблицы feed_actions и message_actions.
- Таски 3 и 4: Запрос для расчета WAU по ленте и мессенджеру и выгрузка в Jupiter.
- Таски 5, 6, 7, 8: Преобразование данных для дальнейшей работы (группировка по дате), чтобы дата воспринималась как отдельный столбец.
- Таск 9: Текст отчета по метрикам ленты и мессенджера.
- Таск 10: Графики метрик за последние 14 дней. Создание plot object для отправки в Телеграмм.
- Таск 11: Графики WAU за последние 2 месяца для ленты и мессенджера. Создание второго plot object для отправки в Телеграмм.

Метрики для feed_actions: DAU, views, likes, CTR, actions_per_user, uniq_posts

Метрики для message_actions: DAU, messages_sent (количество отправленных сообщений), users_received (количество получателей), number_per_user.
